Adoption

Three ways in

New app

Clone, verify, run. Green before you change a line.

npx degit mutaaf/mobile-starter my-app cd my-app && npm install npm run verify npm run ios # or android

Existing web app

Add a sibling and share logic, not components. Your business logic, types and API clients port as-is; your view layer does not.

repo/ web/ # untouched mobile/ # the kit packages/core/ # shared

Existing RN app

Take the conventions, not the scaffold: the jest block, the E2E flows, the CI workflow and the contract.

AGENTS.md package.json → jest .maestro/ .github/workflows/ci.yml

Architecture

One way through

Screens never fetch. They subscribe to a key, and every request goes through one place that owns stale-while-revalidate, single-flight dedup, persistence and instrumentation. A cold start paints from the last session while the network catches up.

1screen — useResource(key, fetcher)
↓
2ResourceCache — SWR, dedup, events, stats
↓
3CacheStore — interface, not an implementation
↓
4TieredStore — memory in front of disk

In-app devtools

Drag the badge, or tap to open an inspector: live cache entries with per-key invalidate, release and evict; a rolling event timeline; hit rate and fetch timings; and network injection — force offline, fail the next request, add latency.

Injection goes through the cache, so it applies to every screen at once and no call site knows it exists.

Measured, not assumed

useFrameCallback is not a vsync counter — it fired ~8×/sec while dumpsys gfxinfo reported a 28 ms median frame. The badge shows JS-thread FPS via rAF, which is honest; the worklet tick rate is labelled as exactly that.

Regression gates

What green means

  • 51 unit tests — cache semantics, API mapping, provider transport, key handling
  • TypeScript strict and ESLint with the React Compiler rules
  • 2 Maestro flows — one structural, one that hits all four live APIs
  • CI on every push — fast checks, plus real Android emulator and iOS simulator jobs
npm run verify # the gate: types + lint + unit

Sixteen invariants, each with its symptom

Written down so a regression is recognised rather than re-derived. A sample:

  • render is async in RNTL v14 — forgetting await makes every query claim render was never called
  • A helper inside a worklet stays a JS function — the UI runtime throws on it
  • Start animations in effects, never useMemo — React may skip a memo body
  • Keys never touch the cache — that tier is plain text and the devtools dumps it
Honest scope

What it is not

No auth, no data layer beyond the demo feeds, no store submission. The E2E suite is two short flows proving the harness works, not coverage. CI runs on emulators and simulators only — no real-device farm. A device-installable IPA needs an Apple Developer account; a sideloadable APK builds locally with no account at all.
